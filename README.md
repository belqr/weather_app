# 🌤️ Weather App – Aplicativo de Clima em Tempo Real
Este é um aplicativo de clima desenvolvido com HTML, CSS e JavaScript puro, com foco em responsividade, interatividade e uma interface divertidade e confortável. Os planos de fundo e ícones foram gerados com inteligência artificial, trazendo um visual único que muda dinamicamente de acordo com as condições climáticas.

# 💡 Propósito
O principal objetivo deste projeto é praticar e demonstrar habilidades em:
- Manipulação da DOM;
- Controle de tempo com setInterval;
- Aplicação de lógica condicional;
- Atualização de conteúdo em tempo real;
- Estilização dinâmica com CSS puro;
- Adaptação da interface para diferentes tamanhos de tela (responsividade).

# 🧪 Tecnologias Utilizadas
- HTML5 – estrutura semântica da aplicação.
- CSS3 – estilos visuais, incluindo planos de fundo dinâmicos e responsividade.
- JavaScript Vanilla – responsável pela lógica de tempo, obtenção do clima e manipulação do DOM.

# ⚙️ Funcionalidades
- 🌍 Clima em tempo real com base na localização do usuário;
- 🌄 Alteração automática do plano de fundo e ícones do clima conforme as condições climáticas (ensolarado, nublado, chuvoso, etc.);
- 📱 Layout responsivo, adaptando-se bem em dispositivos móveis e desktops.
- 🖼️ As imagens e ícones foram gerados via IA. As alterações de fundo transmitem a sensação do clima atual, tornando a experiência mais imersiva.
